# LALAN — Creative Engineer Portfolio

A responsive, no-build static portfolio for creative engineering, IoT, code experiments and mini machines.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For best results, use a local static server or host it on GitHub Pages / Netlify / Vercel.

## Included interactions
- Responsive mobile navigation
- Animated, continuously looping “CODE IT / BUILD IT / BREAK IT / MAKE IT BETTER” ticker
- Custom cursor on mouse/trackpad devices, hover feedback and subtle hero-art parallax
- Project-card hover effects and scroll reveals
- Reduced-motion support and keyboard focus states
- “SAY HELLO” opens an email draft addressed to `lalanofficial.cw@gmail.com`

The contact button uses `mailto:`. It opens the visitor's default email app; it does not send mail automatically. Update the project descriptions and social links as your work grows.
